Ganssle 16-bit shift-register debouncer (db-ganssle.fs)

Each timer tick (5 ms) the ISR shifts a 16-bit state register left, OR's in the P2.0 sample (1 = released, 0 = pressed), and OR's in $E000 to force the top three bits to 1. A single comparison state == $F000 then matches exactly one shape: a 1 in bit 12 (a released sample 12 ticks ago) followed by 12 zeros (12 consecutive pressed samples since). That one comparison does both debouncing AND edge detection — once it fires, the next shift drops bit 12 to 0 and the state can't match $F000 again until another release-then-press transition has been shifted in. No separate shift-on flag is needed.

: shift-isr ( -- )
  shift-state @ 1 lshift                 \ shift window left (16-bit truncates)
  switch? 1 and or                       \ append sample (1=released, 0=pressed)
  $E000 or  shift-state !                \ saturate top 3 bits, store
  shift-state @ $F000 = if
    1 press-count +!  cr press-count @ .
  then ;

Note the sample-sense flip versus db-timer.fs / db-asm.fs: there 1 = pressed; here 1 = released, to match Ganssle's !RawKeyPressed().

What to watch for

  • Idle saturation (ticks 0–15): pin high, sample 1, state walks $0 → $E001 → $E003 → $E007 → … → $FFFF. Bits 15-13 are forced to 1 by the $E000 OR every tick (highlighted in blue); the lower bits fill in as 1s shift through.
  • Bouncing press (ticks 16–21): pin flicks low/high; samples mix; state drifts but does not match $F000 because the bounce keeps inserting 1-bits into the rolling window.
  • Settled (ticks 22 onwards): pressed samples (0) shift in. The state hits $F000 exactly when the last 1 from the idle period has rolled to bit 12 with all-zeros below it — that's the released-sample-12-ticks-ago + 12 consecutive presses pattern. press-count increments. Once.
  • Held: state stays at $E000 while pressing continues. Bit 12 is now 0 (the released marker shifted out), so no further match against $F000 — auto re-arm with no flag.
  • Bouncing release (ticks 33–38): 1-bits start shifting in again from the LSB.
  • Re-saturated (ticks 39 onwards): state walks back up to $FFFF, ready for the next press.
